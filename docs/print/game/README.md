# Print pack

Generated by `npx tsx scripts/print/cards.ts` (set `SITE_URL=https://your-site` first to print the web address on the cards; without it the cards say "on your phone"). Letter paper, print backgrounds on, scale 100% ("actual size"), no headers or footers.

| File | Pages | How to print | Copies / paper |
|---|---|---|---|
| `character-cards.pdf` | 48 (24 cards, front then back) | Double-sided, flip on the long edge | 1 set. Light cream or white paper; card stock if you have it. Hand each guest their own card (alphabetical by public name). |
| `envelope-sheets.pdf` | 24 | Single-sided | 1 set. White or cream paper, folded into each guest's black envelope. |
| `survivor-kit.pdf` | 11 | Single-sided | 1 set, HOST ONLY, contains the solution. Page 1 is the host copy: keep it. Then per survivor: the Flap, and a cut sheet (invitation, marker, address label). Cream paper for the invitation sheets; card stock for the markers. |
| `house-invitations.pdf` | 10 (19 invitations, two per page) | Single-sided | 1 set. Cream card stock. Cut on the dotted line. |
| `door-cards.pdf` | 4 | Single-sided | Page 1 (brief poster) and page 2 (rules poster): 1 each for the door. Page 3 (brief) and page 4 (rules): two half-page copies per sheet for tables; print 2 to 3 sheets of each if you want more table copies. |

The `.html` beside each PDF is the source it was rendered from. Do not edit the PDFs; change the data in `src/data/game` and regenerate.
