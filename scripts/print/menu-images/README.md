# Menu pictures

The menus print a drawn picture for each item. To use your own picture (a photo or an AI image),
save it in this folder with the exact name below (png, jpg or webp), then run
`npm run game:print` and `python3 scripts/print/combine.py`.

| File name | Prompt you can paste into an image generator |
|---|---|
| `bees-knees.png` | A Bee's Knees cocktail in a coupe glass, pale gold, lemon twist, honey, 1920s speakeasy, warm light, top-down-ish, plain dark background |
| `whiskey-sour.png` | A whiskey sour in a rocks glass over ice, amber, orange slice and cherry garnish, 1920s speakeasy, plain dark background |
| `espresso-martini.png` | An espresso martini in a martini glass with a creamy foam top and three coffee beans, plain dark background |
| `bloody-scary.png` | A blood orange prosecco cocktail with Campari and black vodka in a champagne flute, deep red fading to black, orange slice garnish, plain dark background |
| `stuffed-mushrooms.png` | Sausage stuffed mushroom caps with mascarpone, parmesan and herbs on a small plate, plain dark background |
| `salmon-sandwiches.png` | Smoked salmon tea sandwiches on 21 grain bread with herbed butter, cut into triangles, plain dark background |
| `meatballs.png` | Mini Italian meatballs in tomato sauce on a plate with basil, plain dark background |
| `shrimp-cocktail.png` | Classic shrimp cocktail in a glass with cocktail sauce and a lemon wedge, plain dark background |
| `charcuterie.png` | A charcuterie board with artisan cheeses, cured meats, crackers and pepper jam, plain dark background |

Square pictures work best (about 600 x 600 pixels).
